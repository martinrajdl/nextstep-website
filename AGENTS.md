# Nextstep marketing website

This is the independent website repository, not the CRM application. Read README.md before editing. Keep it deployable as a static Vercel project; never copy the CRM database, runtime files, private agent configuration, user records or personal research here.

Keep all demo data fictional. Product claims must match implemented capabilities and confirmed release status. Only advertise downloads after the corresponding signed app and release asset have been verified.

Run pnpm check, pnpm test, pnpm build, and pnpm test:e2e for interaction changes. Check desktop and mobile screenshots. Do not deploy, configure domains, add analytics or send data to external services unless the user requests it.
