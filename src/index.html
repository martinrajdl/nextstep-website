A FEW GOOD QUESTIONS
Does Nextstep include its own AI model?+
No. Your connected MCP-compatible agent runs the workflow using its own tools. It reports progress, sources information, shapes collections, and proposes changes. Nextstep stores the context and shows the lifecycle; it does not run or schedule the agent.
Can I use it without an agent?+
Yes. Manual editing is always available. The primary workflow is agent-operated: you give direction, agents source and organize information, and you review their work in the CRM.
Can trusted agents write directly?+
Proposal review is the default. Explicitly configuring a connection with --allow-writes enables direct changes for a trusted agent. The same validation, version checks, and history still apply.
What does self-hosting mean here?+
Run Nextstep’s backend on your server, open a private SSH tunnel such as ssh -L 4319:127.0.0.1:4319 your-server, and connect from Settings in the Electron app. The local interface stays on your computer and data lives on the server. Keep the same port on both tunnel ends. This is a single-owner workspace.
What happens to the job tracker?+
It stays. The existing job search workspace, stages, preferences, and bounded research connector remain available alongside the new composable collections.
